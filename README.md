## 使用约定

1. **目录**统一采用「两位编号-中文名」命名，编号步长为 10，方便插入新分类。
2. 每个目录下保留 `00-索引.md` 作为该目录的首页与导航。
3. 新建笔记请从 `91-模板/` 复制模板，并填写 frontmatter。
4. 图片、Excalidraw 等附件统一放入 `附件/`。
5. 详细规范见 [[00-总览/04-写作与命名规范|写作与命名规范]]。
