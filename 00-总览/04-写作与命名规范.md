## 二、内容归类规则（10 / 50 / 80 三分法）

同一主题常横跨多个分类，判断顺序是**先看内容性质，再定归属**：

| 内容性质 | 归属 | 典型内容 |
| --- | --- | --- |
| 讲 **原理** | `10-计算机基础/` | 进程调度、虚拟内存、TCP 三次握手、算法复杂度 |
| 讲 **操作 / 运维** | `50-运维与DevOps/` | 发行版使用、命令、服务、部署、排障 |
| 讲 **工具 / 环境怎么装怎么配** | `80-工具与环境/` | 装 JDK、配 shell、构建工具、IDE 设置 |

> 一句话记忆：**原理进 10，运维进 50，环境配置进 80。**

**同一主题的分流示例：**

| 主题 | 落点 |
| --- | --- |
| Linux 内核 / VFS 等机制 | `10-计算机基础/10-操作系统/` |
| Ubuntu 的 apt 源、systemd、桌面、排障 | `50-运维与DevOps/10-Linux/`（发行版专属内容可在其下再建 `Ubuntu/`） |
| 在 Ubuntu 上装 JDK、配 shell 环境 | `80-工具与环境/50-环境配置/` |
| Maven 加入 PATH、配置镜像 | `80-工具与环境/20-构建工具/10-Maven/` |
| Obsidian 插件、同步、快捷键 | `80-工具与环境/40-IDE与编辑器/10-Obsidian/` |
| Git 通用命令与工作流 | `80-工具与环境/10-版本控制/` |

**不属于上述三分时的判定顺序：**

1. 语言本身的语法与特性 → `20-编程语言/`；语言的**框架 / 生态** → 对应领域（如 Spring → `30-后端开发/`）。
2. 数据的存取与检索 → `70-数据库与存储/`；数据分析与建模 → `60-数据与AI/`。
3. 具体项目的落地过程与反思 → `90-项目与实战/`。

**归属冲突时**，以「读者会去哪里找」为准；必要时在相关目录的 `00-索引.md` 加交叉引用。

## 三、命名规范

### 目录
- 格式：`<两位编号>-<中文名称>`，例如 `30-后端开发`。
- 编号步长为 **10**（10、20、30…），便于日后在中间插入新分类。
- 名称中不得出现空格或 `# ^ [ ] | / \ : * ? " < >` 等字符。

### 笔记文件
- 中文标题，**不加**编号前缀，例如 `GC 调优实战.md`。
- 同一主题的多篇笔记，可在目录内用子目录再分层。
- 每个目录保留 `00-索引.md` 作为该目录首页。

### 附件
- 带附件的笔记采用「笔记同名文件夹」结构，附件放在其中的 `assets/`：

  ```
  <笔记名>/
  ├── <笔记名>.md
  └── assets/
      └── <图片>
  ```

- Obsidian 默认附件位置已设为「当前文件夹下的 `assets/`」，新建附件会自动就近落位。
- 文件名用小写英文或拼音 + 连字符，例如 `spring-bean-lifecycle.png`，避免中文名；`assets/` 内不重名即可，但**全库可能重名**。
- 引用使用**相对路径**：`![[assets/文件名.png]]`（Obsidian「新建链接格式」= 相对路径），**不要**用裸文件名，避免全库同名歧义。
- 顶层 `附件/` 保留给跨笔记共用或历史遗留资源。

## 四、笔记规范

- 每篇笔记包含 YAML frontmatter：

  ```yaml
  ---
  title: 标题
  date: 2026-10-15
  tags:
    - 主题标签
    - 状态标签
  ---
  ```

- 使用 **wikilink** 建立关联：`[[目录/笔记|显示名]]`，靠双链构建知识网络。
- 标签分两类：**分类标签**（`#后端` `#前端` `#运维`）与 **状态标签**（`#待整理` `#进行中` `#归档`）。
- 长笔记先写结论（TL;DR），再展开细节。
- **标点与强调**：全库统一使用中文双引号 `“”`，**不再使用直角引号 `「」`**；需要强调引号内的内容时，把引号内的文字加粗。
  - 示例：`「有范围、有期限、可撤销」` → “**有范围、有期限、可撤销**”

## 五、新增内容流程

1. 判断归类：属于哪个一级分类？没有合适的就新建（用下一个可用的 10 的倍数编号）。
2. 在对应目录新建笔记，或从 `91-模板/` 复制模板。
3. 更新该目录的 `00-索引.md`，把新笔记挂进导航。
4. 在 [[00-总览/03-更新日志|更新日志]] 记一笔。
